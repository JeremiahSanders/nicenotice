# Validators.WithDelegateValidator&lt;TEnterpriseEventBaseType&gt; method

Configures this typed notice builder to use a validator that executes a custom validation function, *genericValidatorFunction*.

```csharp
public static TypedNoticesBuilder<TEnterpriseEventBaseType>

    this TypedNoticesBuilder<TEnterpriseEventBaseType> builder,

    Func<object, string, IReadOnlyList<string>?> untypedValidatorFunction)
```

| parameter | description |
| --- | --- |
| TEnterpriseEventBaseType | A base type for the application's enterprise event notifications. |
| builder | This typed notice builder. |
| genericValidatorFunction | A custom validation logic function which is invoked from [`ITypedNoticeDispatcher`](../ITypedNoticeDispatcher-1.md). Use of `static` delegates is highly recommended. |
| untypedValidatorFunction | A custom validation logic function which is invoked from [`ITypedNoticeDispatcher`](../ITypedNoticeDispatcher.md). Use of `static` delegates is highly recommended. |

## Return Value

Returns this typed notice builder for further configuration.

## Remarks

This is the easiest way to add custom validation logic to enterprise event notifications. Provide a `static` delegate *genericValidatorFunction* and it will be called for each enterprise event dispatched.

The use of two validator functions, *genericValidatorFunction* and *untypedValidatorFunction*, is needed to support the breadth of typed notification dispatching interfaces.
