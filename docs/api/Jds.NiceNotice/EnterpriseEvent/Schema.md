# EnterpriseEvent.Schema property

Gets the schema identifier of this enterprise event. Default: The type name.

```csharp
public string Schema { get; set; }
```

## Remarks

This property is intended to support JSON Schema. This declares the schema to which this event conforms.

Optimally, this will be set to a resolvable URL which provides a JSON Schema document. Such configuration supports developer and diagnostic tools, e.g., IDEs.

[ See JSON Schema documentation for $schema. ](https://json-schema.org/understanding-json-schema/keywords#dollarschema)
