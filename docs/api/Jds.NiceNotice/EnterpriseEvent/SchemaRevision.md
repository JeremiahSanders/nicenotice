# EnterpriseEvent.SchemaRevision property

Gets the revision index of this enterprise event data transfer object schema.

```csharp
protected virtual int? SchemaRevision { get; set; }
```

## Remarks

This property is used to provide schema revision/change information, with the assumed initial revision being 0. When not null this value is, by default, incorporated into [`Schema`](./Schema.md).

The default [`Schema`](./Schema.md) pattern, `Title@Revision` (e.g., `Logout@3`, allows applications to communicate and document an expectation.
