# StreamSelectors.TypeNameStreams&lt;TEnterpriseEventBaseType&gt; method

Creates a notice stream selector which sends events to streams using their type name.

```csharp
public static NoticeStreamSelector<TEnterpriseEventBaseType> 
    TypeNameStreams<TEnterpriseEventBaseType>(bool useFullTypeName = false)
```

| parameter | description |
| --- | --- |
| TEnterpriseEventBaseType | A base enterprise event notice type. |
| useFullTypeName | A value indicating whether the type name (e.g., `UserLogin`) or the full type name (e.g., `MyOrganization.MyApp.UserLogin`) should be used when determining the [`EventStreamId`](../EventStreamId.md). |

## Return Value

Returns the constructed stream selector.

## Remarks

This is a very common routing strategy. Custom implementations of [`INoticeIo`](../INoticeIo.md) could use the `nameof` keyword within a `switch` statement to connect logical event streams to their I/O destination (e.g., SNS topic).
