| parameter | description |

## Return Value

Returns a notice stream selector.

## Remarks

Use this stream selector when events should all be routed to the same destination (e.g., AWS SNS topic).

If any events need to be routed to alternate destinations: use [`TypeMap`](./TypeMap.md) to route events based upon an event type to destination map, or use [`Delegate`](./Delegate.md) to provide custom routing logic.
