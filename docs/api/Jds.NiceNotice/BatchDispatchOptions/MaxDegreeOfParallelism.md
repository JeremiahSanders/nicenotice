# BatchDispatchOptions.MaxDegreeOfParallelism property

Gets a value indicating the maximum degree of parallelism to use when dispatching in parallel. A value of `-1` is unlimited parallelism, and a value of `1` is serial dispatch.

```csharp
public int MaxDegreeOfParallelism { get; set; }
```

## Remarks

This value directly corresponds to MaxDegreeOfParallelism. If your [`INoticeIo`](../INoticeIo.md) is not thread-safe, DO NOT SET THIS VALUE TO ANYTHING OTHER THAN 1.

Note that implementations of [`INoticeBatchIo`](../INoticeBatchIo.md) may choose to ignore this value. Further, implementations might not support parallel dispatch.

If your [`INoticeIo`](../INoticeIo.md) implementation does NOT support batched dispatch (does not implement [`INoticeBatchIo`](../INoticeBatchIo.md))... The default [`TypedNoticeDispatcher`](../TypedNoticeDispatcher-1.md) and [`TypedNoticeDispatcher`](../TypedNoticeDispatcher.md) will use this to when invoking your [`DispatchAsync`](../INoticeIo/DispatchAsync.md) in parallel.
