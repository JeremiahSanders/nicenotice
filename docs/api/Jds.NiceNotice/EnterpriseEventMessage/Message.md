# EnterpriseEventMessage.Message property

Gets the message associated with this enterprise event.

```csharp
public string Message { get; set; }
```

## Remarks

Use caution with the length of values assigned to this property.

NiceNotice is expressly designed to simplify sending typed notifications to enterprise event buses which have message payload size limits. Generic message fields which convey information in human-readable string form (rather than discrete data properties) can exceed the size limits of the underlying event bus, yielding runtime exceptions.
