# TypedNoticesBuilder&lt;TEnterpriseEventBaseType&gt;.UseStreamSelector method (2 of 2)

Configures the algorithm used to identify the stream to which a notice should be dispatched (determining its [`EventStreamId`](../EventStreamId.md)).

```csharp
public TypedNoticesBuilder UseStreamSelector(
    Func<IServiceProvider, NoticeStreamSelector<TEnterpriseEventBaseType>> factory, 
    ServiceLifetime lifetime)
```

| parameter | description |
| --- | --- |
| factory | A factory method which receives an IServiceProvider and returns an implementation of [`NoticeStreamSelector`](../NoticeStreamSelector-1.md). |
| lifetime | A service lifetime for the stream selector created by the *factory*. |

## Return Value

Returns this instance for further configuration.

## Remarks

See [`StreamSelectors`](../StreamSelectors.md) for helper methods to create stream selectors.

Most projects find TypeNameFactory a good option, sending every notice to a stream matching its type name.

For precise, type-based configuration, [`TypeMap`](../StreamSelectors/TypeMap.md) is a good fit.

In many custom cases, you can use the [`Delegate`](../StreamSelectors/Delegate.md) stream selector to provide custom routing logic. Use of `static` lambda methods is recommended.

Finally, [`NoticeStreamSelector`](../NoticeStreamSelector-1.md) is abstract, so you can create a custom implementation for the most control.
