## Remarks

See [`Routers`](../../Jds.NiceNotice.TypedNotices.Routing/Routers.md) for helper methods to create stream selectors.

Most projects find TypeNameFactory a good option, sending every notice to a stream matching its type name.

For precise, type-based configuration, [`TypeMap`](../../Jds.NiceNotice.TypedNotices.Routing/Routers/TypeMap.md) is a good fit.

In many custom cases, you can use the [`Delegate`](../../Jds.NiceNotice.TypedNotices.Routing/Routers/Delegate.md) stream selector to provide custom routing logic. Use of `static` lambda methods is recommended.

Finally, [`NoticeRouter`](../../Jds.NiceNotice.TypedNotices.Routing/NoticeRouter-1.md) is abstract, so you can create a custom implementation for the most control.
