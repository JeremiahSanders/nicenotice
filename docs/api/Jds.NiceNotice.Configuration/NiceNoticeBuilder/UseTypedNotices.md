# NiceNoticeBuilder.UseTypedNotices method (1 of 4)

Adds support for dispatching typed, serialized notices (JSON most commonly) using the default [`EnterpriseEvent`](../../Jds.NiceNotice/EnterpriseEvent.md) as the assumed base type.

```csharp
public NiceNoticeBuilder UseTypedNotices(Action<TypedNoticesBuilder<EnterpriseEvent>> configure, 
    ServiceLifetime dispatcherServiceLifetime)
```

| parameter | description |
| --- | --- |
| configure | A method which configures the handling of typed notices. |
| dispatcherServiceLifetime | A service lifetime to assign the [`ITypedNoticeDispatcher`](../../Jds.NiceNotice/ITypedNoticeDispatcher-1.md) service. The typed notice dispatcher depends upon the configured [`INoticeIo`](../../Jds.NiceNotice/INoticeIo.md) (such as the adapters provided by `NiceNotice.Aws.Sns` NuGet package). Be considerate of the thread-safety and best practices of your I/O implementation. |

Returns this instance.
