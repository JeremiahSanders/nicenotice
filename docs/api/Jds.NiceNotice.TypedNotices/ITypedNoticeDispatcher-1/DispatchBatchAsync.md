# ITypedNoticeDispatcher&lt;TEnterpriseEventBaseType&gt;.DispatchBatchAsync&lt;TEventType&gt; method

Dispatches a batch of enterprise event notices to logical event streams using the configured [`INoticeIo`](../../Jds.NiceNotice.Dispatching/INoticeIo.md).

```csharp
public Task<BatchTypedNoticeDispatchResult> DispatchBatchAsync<TEventType>(
    DispatchBatchRequest<TEventType> request, CancellationToken cancellationToken = default)
    where TEventType : TEnterpriseEventBaseType
```

| parameter | description |
| --- | --- |
| TEventType | A notice event type. Must be a non-nullable type which inherits from *TEnterpriseEventBaseType*. By default, this generic type argument implies that all notices are of the same type. However, if you invoke this method with a common base type, such as *TEnterpriseEventBaseType*, then notices of different types can be dispatched together in a single batch. |
| request | A batch notice dispatch request. |
| cancellationToken | An asynchronous operation cancellation token. |

## Return Value

Returns the result of dispatching the batch of notices.

## Remarks

The default implementation applies (in order): (1) logical routing, (2) serialization, (3) validation, and (4) dispatch to I/O using an [`INoticeIo`](../../Jds.NiceNotice.Dispatching/INoticeIo.md).
