# NoticeStreamAttribute constructor

An attribute indicating the logical identifier of the notice stream to which a notice type should be sent. I.e., the [`EventStreamId`](../../Jds.NiceNotice/EventStreamId.md) value.

```csharp
public NoticeStreamAttribute(string streamName)
```

| parameter | description |
| --- | --- |
| streamName | The logical identifier of the notice stream to which this notice type should be sent. I.e., the [`EventStreamId`](../../Jds.NiceNotice/EventStreamId.md) value. (E.g., `user-session`) NOT an I/O address. |

## Remarks

This attribute is intended to be used on notice types. I.e., objects which descend from [`EnterpriseEvent`](../../Jds.NiceNotice/EnterpriseEvent.md) or the runtime application's equivalent.
