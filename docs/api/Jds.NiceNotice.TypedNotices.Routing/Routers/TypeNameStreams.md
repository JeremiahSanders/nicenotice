# Routers.TypeNameStreams&lt;TEnterpriseEventBaseType&gt; method

Creates a notice stream selector which sends events to streams using their type name.

```csharp
public static NoticeRouter<TEnterpriseEventBaseType> TypeNameStreams<TEnterpriseEventBaseType>(
    bool useFullTypeName = false)
```

| parameter | description |
| --- | --- |
| TEnterpriseEventBaseType | A base enterprise event notice type. |
| useFullTypeName | A value indicating whether the type name (e.g., `UserLogin`) or the full type name (e.g., `MyOrganization.MyApp.UserLogin`) should be used when determining the [`EventStreamId`](../../Jds.NiceNotice/EventStreamId.md). |

## Return Value

Returns the constructed stream selector.

## Remarks

This is a very common routing strategy. Custom implementations of [`INoticeIo`](../../Jds.NiceNotice/INoticeIo.md) could use the `nameof` keyword within a `switch` statement to connect logical event streams to their I/O destination (e.g., SNS topic).
