# Routers.TypeMap&lt;TEnterpriseEventBaseType&gt; method

Creates a notice stream selector which uses the provided type *map* and optional *defaultStream* to specify where events should be routed.

```csharp
public static NoticeRouter<TEnterpriseEventBaseType> TypeMap<TEnterpriseEventBaseType>(
    IReadOnlyDictionary<Type, EventStreamId> map, EventStreamId? defaultStream = default)
```

| parameter | description |
| --- | --- |
| TEnterpriseEventBaseType | The base enterprise event type. |
| map | The type map which defines where each type (assumed to be derived from *TEnterpriseEventBaseType*) should be routed. |
| defaultStream | The default stream which should receive all events not included in *map*. |

## Return Value

Returns a notice stream selector.

## Remarks

Use this stream selector to declaratively define event routing.

It is strongly recommended to use the *defaultStream* to ensure that all events have a destination. Without a default, dispatching any event types that are not included in *map* will instead trigger a [`NoticeRoutingException`](../NoticeRoutingException.md).
